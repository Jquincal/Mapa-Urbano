# android-app

Directorio reservado para la aplicación Android nativa con Kotlin y Jetpack Compose. Esta entrega actualiza diseño y documentación; no implementa la aplicación.

La cuenta del vecino es opcional: los reportes `account` se consultan en Mis reportes y los `anonymous` mediante un código opaco. El anónimo no se vincula posteriormente a una cuenta.

La referencia visual es MuniReport en Stitch. La navegación, los estados, scroll, transiciones y contratos por acción están en [UX e interfaces](../docs/05-ux-e-interfaces.md); los resultados reales y límites del prototipo, en [verificación de Stitch](../docs/13-verificacion-stitch.md). El HTML exportado no sustituye Compose ni amplía el MVP.
